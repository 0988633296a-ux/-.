# พื้นที่และหน่วยงาน

หน่วยงานเริ่มต้น: ปภ. ตำบลลำห้วยหลัว อำเภอสมเด็จ จังหวัดกาฬสินธุ์ ตามข้อมูลจากผู้ใช้

จุดกึ่งกลางแผนที่อ้างอิงข้อมูล OpenStreetMap ผ่าน Nominatim: สมเด็จ, ลำห้วยหลัว, อำเภอสมเด็จ, จังหวัดกาฬสินธุ์ ประเทศไทย (OSM node 493290195), 16.6971878, 103.7459312 ตรวจสอบ 7 ตุลาคม 2569

จุดอ้างอิงนี้เป็นตำแหน่งพื้นที่สมเด็จในตำบลลำห้วยหลัว ไม่ใช่พิกัดสำนักงาน ปภ. หรือสถานีจริง หมุดเหตุ จุดศูนย์ โรงพยาบาล แหล่งน้ำ และศูนย์อพยพในโหมดตัวอย่างยังเป็นจุดตัวอย่างเท่านั้น

ข้อมูลจริงใช้พิกัดของเหตุและ locations ที่หน่วยงานบันทึกเอง ชื่อหน่วยงานจริงอ่านจาก organizations ของ Supabase

ผู้ใช้ที่เคยเปิดรุ่นเชียงใหม่: ปรับเฉพาะที่อยู่และพิกัดของเหตุเริ่มต้นเดิมที่ยังใช้ที่อยู่เดิม ชื่อหน่วยในตัวอย่างและจังหวัดทะเบียนตัวอย่าง รักษาเหตุที่สร้างเองและประวัติ/ภาพ/สถานะไว้
