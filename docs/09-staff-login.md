# เข้าสู่ระบบเจ้าหน้าที่ ปภ. ลำห้วยหลัว

1. เปิดเว็บและกด **เข้าสู่ระบบ** บนแถบด้านบน ใช้อีเมลและรหัสผ่านของบัญชีที่ผู้ดูแลกำหนดให้
2. ระบบตรวจบัญชีด้วย Supabase Auth และโหลดสิทธิ์จาก `public.users` ก่อนเปิดข้อมูลหน่วยงานจริงโดยอัตโนมัติ ข้อมูลตัวอย่างไม่ถูกนำเข้าฐานข้อมูลจริง
3. หลังรีโหลดหน้า ระบบกลับเข้าข้อมูลจริงเมื่อมี session เดิมและออนไลน์ หากโหลดไม่สำเร็จจะยังแสดงป้ายข้อมูลตัวอย่าง ผู้ใช้กดเข้าสู่ระบบเพื่อลองใหม่ได้
4. เมนู **บัญชีผู้ใช้** เปิดหน้าการตั้งค่า เพื่อซิงก์ข้อมูลหรือออกจากระบบ หากมีคำสั่งรอส่งต้องซิงก์ก่อน การหมดอายุบัญชีหรือออกจากระบบไม่ลบคิวข้อมูลของบัญชีเดิม

## ลืมรหัสผ่าน

ปุ่ม **ลืมรหัสผ่าน** ส่งคำขอผ่าน `resetPasswordForEmail` กลับมาที่ `/?auth=recovery` ต้องเปิดลิงก์ในอีเมลเพื่อรับ session ก่อนตั้งรหัสผ่านใหม่อย่างน้อย 12 ตัวอักษร URL ของเว็บต้องอยู่ในรายการ Redirect URLs ของ Supabase

หน้ารับคำขอไม่เปิดเผยว่าอีเมลใดมีบัญชี การส่งอีเมลจริงขึ้นกับ SMTP และข้อจำกัดของโปรเจกต์ Supabase SMTP เริ่มต้นส่งได้เฉพาะอีเมลที่ได้รับอนุญาตในทีมโปรเจกต์ สำหรับเจ้าหน้าที่หลายคนต้องตั้ง Custom SMTP การทดสอบในครั้งนี้ใช้ mock transport สำหรับอีเมลและลิงก์กู้รหัสผ่าน ไม่ได้ส่งอีเมลจริงหรือเปลี่ยนรหัสผ่านผู้ดูแล

## เพิ่มบัญชีเจ้าหน้าที่

ผู้ดูแลเพิ่มบัญชีผ่าน Supabase Auth แล้วผูก UUID กับ `public.users` ของหน่วยงานและกำหนดบทบาทตาม [การตั้งค่า Supabase](07-supabase-live.md) เจ้าหน้าที่ภาคสนามต้องผูก `staff.user_id` ด้วย ระบบไม่มีการสมัครเองหรือเลือกบทบาทเพื่อรับสิทธิ์จริง

สิทธิ์อ่านและเขียนตรวจด้วย RLS/RPC ฝั่งฐานข้อมูล ไม่มี service role ในเบราว์เซอร์ สถานะ session ในเครื่องใช้แสดงผล ไม่ใช่หลักฐานให้ข้ามสิทธิ์ฐานข้อมูล

## การตรวจสอบ

`node tests/login.mjs` ทดสอบรหัสผ่านผิด บัญชีไม่มีโปรไฟล์หน่วยงาน การเปิดข้อมูลจริง การคืน session หลังรีโหลด ออกจากระบบ หน้าจอมือถือ การรับลิงก์และเปลี่ยนรหัสผ่าน และการปฏิเสธหน้ากู้รหัสผ่านที่ไม่มีลิงก์ยืนยัน โดยใช้ mock Auth transport

ตรวจฐานข้อมูลจริงแล้ว ตาราง users, incidents, staff, vehicles, incident_photos และ audit_logs เปิด RLS และไม่มีสิทธิ์อ่านสำหรับ anon บัญชีผู้ดูแลเดิมยืนยันอีเมลแล้ว

การเข้าชมเว็บ Sites ยังมีสิทธิ์การแชร์แยกจากบัญชี Supabase การปรับล็อกอินนี้รักษาผู้ชมเว็บเดิมไว้ หากต้องการให้เจ้าหน้าที่คนอื่นใช้งาน ต้องเพิ่มสิทธิ์เข้าชมเว็บและบัญชีหน่วยงานทั้งสองส่วน
