# Information Architecture

หน้าหลัก: KPI วันนี้ เหตุเร่งด่วน แผนที่ ความพร้อม เหตุล่าสุด
เหตุ: รับแจ้ง ค้นหา รายละเอียด จัดกำลัง Checklist Timeline ภาพ ปิดเหตุ รายงาน
แผนที่: เหตุ จุดสำคัญ พื้นที่เสี่ยง
ทรัพยากร: กำลังพล รถ อุปกรณ์
เพิ่มเติม: สถิติ รายงาน API การแจ้งเตือน Audit ผู้ใช้ การเชื่อมต่อ
