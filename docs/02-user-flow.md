# User Flow

รับแจ้ง → ตรวจสอบ → มอบหมายกำลังพล/รถ/อุปกรณ์ → Checklist → ออกปฏิบัติการ → ถึงเหตุ → ดำเนินการ → ภาพก่อน/ระหว่าง/หลัง → ควบคุมเหตุได้ → ผลการดำเนินงาน → ปิดเหตุ → Preview/Print/PDF/Share
ทุกสถานะบันทึกเวลา ผู้กด ค่าเดิม/ใหม่; ห้ามจองทรัพยากรซ้ำ; คืนทรัพยากรเมื่อปิดเหตุ
Offline: draft + operation UUID + version ในเครื่อง → online → RPC idempotent → conflict ไม่เขียนทับเงียบ
